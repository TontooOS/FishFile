# Tontoo FishFile

Fish Config (`.fico`) — a lightweight, human-friendly config format for TontooOS. Parse, create and edit `.fico` files like JSON/YAML, with native nesting, comments and type-aware values.

## Made for TontooOS

Explore more at https://github.com/TontooOS/Libs


## Adding to Your Project

Add to your `Cargo.toml`:

```toml
[dependencies]
sdk = { path = "/Library/System/sdk", features = ["FishFile"] }
```
